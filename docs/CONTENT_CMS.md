# 官网内容管理

在 VMPM 登录管理员账号，从侧栏“官网内容”进入。首版内嵌原 Vue 编辑器，身份由 VMPM 统一校验，无需再次输入官网密码。完整运行方式、协议、联调、部署顺序和回滚见 [动态官网说明](DYNAMIC_SITE.md)。

## 编辑与发布

- 内容库按文档、整合包和地图分组，支持路径搜索、新建、复制和批量发布。
- 停止输入约 1.2 秒自动保存草稿；`Ctrl+S`、`Cmd+S` 或“立即保存”可马上保存。
- 草稿不会改变公开版本。发布前检查通过后，发布会更新数据库并刷新缓存，新请求即可看到新版内容，无需构建。
- 下线后公开页返回 404，并从动态列表、搜索和 sitemap 移除。
- 多窗口编辑使用草稿版本号防止覆盖；出现冲突时先确认保留哪个版本。
- 下载配置保存在独立表中，保存后即时生效；正文保留 `<DownloadLinks/>`。项目目录和最新文件继续在 VMPM 资源管理中配置。

## 历史与恢复

每次发布保存历史版本。恢复历史只将其复制为草稿，再次发布后才更新网站。后台设置中的“刷新站点缓存”可重新读取已发布内容，不改变草稿和历史。

## 导入与备份

已有页面、ID、发布历史和下载配置继续使用现有数据库，无需重新迁移。首次初始化 CMS 应先导入完整内容，再进行单页发布。数据库没有发布历史时保留仓库 Markdown 回退；保存首个草稿不会影响公开页，已经下线的内容不会通过回退重新出现。

`pnpm content:migrate` 导入仓库 Markdown；`pnpm content:export` 将页面草稿及发布版本导出到未纳入 Git 的 `content-export/`，非空目录不会覆盖，可使用 `--output` 指定新目录。

统一登录下，CLI 通过 `VMPM_TOKEN` 环境变量使用当前管理员会话，`VMPM_ORIGIN` 默认为官方 VMPM 来源。请通过私有环境配置提供令牌，不将其写入命令参数、仓库或日志。日常备份应包含内容、下载配置和私有会话表。

生产模式默认使用 VMPM 统一登录。开发模式未配置 SSO 时保留旧挑战响应登录用于独立开发；它不影响生产的管理员权限校验。
